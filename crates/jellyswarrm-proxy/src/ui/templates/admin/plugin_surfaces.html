Pin suits anything that belongs to one server's copy of a plugin — its configuration, or an endpoint that identifies the caller. Merge suits anything that reports on media, because one server only knows about its own. Pinning something that reports on media is the mistake worth avoiding: nothing errors, the page simply shows part of the catalogue. Sending a plugin to one server is for the case neither of those describes: an integration that only exists on one of your servers, such as the one that actually talks to Jellyseerr. It overrides Pin and Merge for that plugin.
